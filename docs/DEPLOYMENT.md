# Deployment

Target: `https://togetherwork-ops-ai.rahulpaul.net` on Cloudflare Pages, with the Claude calls running in a Pages Function.

```
Browser -> Cloudflare Pages (static Vite build)
        -> POST /api/claude   (Pages Function: functions/api/claude.js)
        -> Anthropic API      (key is a server-side secret)
```

## What changed from the original prototype

The original prototype called Anthropic directly from the browser using `VITE_CLAUDE_API_KEY` and the `anthropic-dangerous-direct-browser-access` header. Any key placed in a Vite `VITE_*` variable is compiled into the public JavaScript. That is fine for a local prototype and unsafe for a public site. The public deployment therefore adds a server-side boundary:

- The browser sends `{ operation, payload }` (`triage`, `response` or `implementation`) and never a prompt, model name or key.
- Prompts live in `functions/_lib/prompts.js` and are not in the browser bundle.
- The function validates and truncates fields, caps request size and output tokens, checks the request origin, rate limits, and maps upstream errors to safe responses.
- `ANTHROPIC_API_KEY` exists only as a Cloudflare Pages secret (and in a local, gitignored `.env`).

These are public-deployment hardening changes; the prompts, JSON parsing and UI behavior are the original design.

## Cost and abuse protection

A public unauthenticated AI demo can generate spend. Layers, from the code outward:

1. Fixed operation set, fixed model, per-operation `max_tokens` (700 / 900 / 1800), 16 KB body limit, per-field length caps.
2. Same-origin check (`Origin` must match the site or `ALLOWED_ORIGINS`).
3. Best-effort rate limit per IP (default 20 calls per 10 minutes) and per server instance (default 300). Cloudflare can run several isolates, so this bounds bursts rather than guaranteeing a global cap.
4. Kill switch: set `AI_ENABLED=false` and the app falls back to labelled offline samples without redeploying code.
5. **Anthropic workspace spend limit (do this):** create a dedicated key in its own workspace and set a low monthly limit in the Anthropic console. This is the real hard cap.
6. Optional: a Cloudflare WAF rate-limiting rule on `/api/claude` (Security > WAF > Rate limiting rules).

When the AI is unavailable, rate limited or erroring, the app keeps working and shows rule-based samples labelled "Offline sample · AI unavailable". Analytics does not count those samples as AI actions.

## One-time setup (needs the account owner)

```bash
# 1. Create the Pages project (direct upload; no Git build needed)
npx wrangler@4 pages project create togetherwork-ops-ai --production-branch main

# 2. Set the server-side secret (prompts for the value; it is never printed or committed)
npx wrangler@4 pages secret put ANTHROPIC_API_KEY --project-name togetherwork-ops-ai

# 3. Build and deploy from main
npm ci
npm run deploy
```

The deployment is available at `https://togetherwork-ops-ai.pages.dev` immediately. Keep that URL as the rollback/debug address.

### Custom domain

Cloudflare dashboard -> Workers & Pages -> `togetherwork-ops-ai` -> Custom domains -> add `togetherwork-ops-ai.rahulpaul.net`. Because `rahulpaul.net` is already on Cloudflare DNS, the CNAME and certificate are created automatically. Wait for the status to become Active, then check the domain over HTTPS.

### Optional variables (plain text, Pages -> Settings -> Variables)

| Name | Default | Purpose |
|---|---|---|
| `AI_ENABLED` | on | `false` turns AI off (offline-sample mode) |
| `RATE_LIMIT_PER_IP` | 20 | AI calls per 10 min per client IP, per instance |
| `RATE_LIMIT_GLOBAL` | 300 | AI calls per 10 min per instance |
| `ALLOWED_ORIGINS` | none | extra origins allowed to call `/api/claude` |

## Verify after deployment

1. `GET /api/claude/status` returns `{"aiAvailable":true,...}`; the top bar shows "Claude Sonnet 4.6 · Live".
2. Open a ticket: triage and draft appear without the "Offline sample" label.
3. Expand an implementation: checklist generated by the model.
4. Direct links work and survive refresh: `/support`, `/implementations`, `/knowledge`, `/managed-services`, `/analytics`.
5. `grep -R "sk-ant" dist` finds nothing, and the browser network tab shows only same-origin `/api/claude` calls.

## Rollback

Redeploy a previous commit with `npm run deploy`, or set `AI_ENABLED=false` to stop all model calls immediately.

## Local development

```bash
cp .env.example .env     # add ANTHROPIC_API_KEY (server-side only)
npm run dev              # the Vite middleware serves /api/claude with the same handler
npm run pages:dev        # optional: run the real Pages runtime against a production build
```
